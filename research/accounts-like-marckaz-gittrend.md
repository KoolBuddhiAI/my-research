# Accounts similar to @marc.kaz and @gittrend_io

_Researched 2026-10-18 via web search (no platform login). Direct profile fetches are blocked from the
research environment, so profiles were identified from indexed posts. Follower counts were not verified._

## What the two reference accounts do
- **Marc Kaz** ([Instagram @marc.kaz](https://www.instagram.com/marc.kaz), [Threads @marc.kaz](https://www.threads.com/@marc.kaz), [X @marckaz](https://x.com/marckaz)):
  a creator ("learn ai with me!") who posts short showcases of free open-source AI tools on GitHub, in a
  "Ships with: • … • …" format. Examples: MoneyPrinterTurbo (AI short-video generator), Skylos (catches
  invented code in AI output), Open Design, Databasement.
- **GitTrend** ([X @gittrend_io](https://x.com/gittrend_io), [gittrend.io](https://gittrend.io/about)): a GitHub discovery engine.
  Daily trending repos, topic and language filters, historical rankings, free API.

Common theme: **"here's a trending / free open-source GitHub repo, and what it does."**
